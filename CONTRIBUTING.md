# Contributing to Sinatra Kamal Duo

Thank you for contributing to Sinatra Kamal Duo! Your contributions and time are much appreciated. If you are fixing a bug, please (report the issue)[https://github.com/scarver2/kamalduo/issues] first.

## Submitting a Pull Request
1. Fork KamalDuo (https://github.com/scarver2/kamalduo/fork)
2. Create a feature branch (`git checkout -b my-new-feature`)
3. Commit changes (`git commit -am 'Add some feature'`)
4. Push the branch to GitHub (`git push origin my-new-feature`)
5. Submit a Pull Request (https://github.com/scarver2/kamalduo/pulls)
